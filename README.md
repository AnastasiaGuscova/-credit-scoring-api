# Credit Scoring API

API кредитного скоринга с интерпретируемыми решениями (SHAP) 
и воспроизводимым MLflow-трекингом.

## Бизнес-контекст
Сервис оценивает вероятность дефолта клиента и возвращает 
решение с объяснением топ-3 факторов, 
повлиявших на скоринг. Соответствует требованиям регуляторики 
к объяснимости кредитных решений.
API на FastAPI используется для интеграции с бэкенд-системами банка. Flask-приложение используется как демо-интерфейс для визуализации работы модели

## Ключевые метрики
- ROC-AUC
- Gini = 2*AUC - 1
- KS-статистика

## Технологии
CatBoost, SHAP, FastAPI, MLflow, Docker, pytest
